# Мистер Фло — демонстрационный сайт

Адаптивный сайт на React, TypeScript и Vite. Каталог, фильтры по поводу и бюджету, карточки букетов, избранное на время сеанса, подбор букета, редактируемый запрос, копирование и переход в сообщения ВК. Без сервера и автоматической отправки сообщений.

## Запуск

`npm install` · `npm run dev` · `npm run build` · `npm test`

Каталог и шаблон запроса: `src/catalog.ts`. Стили: `src/style.css`.
События для подключения аналитики: `window.addEventListener('flo:analytics', event => ...)`. Поле `event.detail.name`: `bouquet_view`, `picker_complete`, `request_copy`, `vk_open`. События не отправляются внешним сервисам. Клик в ВК не означает продажу.

## Показ владельцу за 2 минуты

1. Открыть первый экран с телефона: выразительный образ магазина и понятный выбор букета.
2. Нажать «Спасибо» и выбрать бюджет: клиент видит подходящие варианты вместо переписки с нуля.
3. Открыть букет: состав, примерная цена и действие рядом.
4. Нажать «Хочу такой», скопировать запрос и открыть ВК: магазин продолжает работать в привычном канале.
5. Показать подбор для тех, кто не знает, что выбрать, и ссылки на отзывы и расположение.

Польза: проще выбрать подарок, меньше первичных уточнений, единая страница для рекламы и ссылок из соцсетей. Рост заказов нужно измерять после запуска; демо не обещает финансовый результат.

## Перед публичным запуском

- Получить разрешение на использование бренда, утвердить дизайн и тексты с владельцем.
- Заменить иллюстрации из Unsplash реальными разрешёнными фото студии и букетов; подтвердить состав, цены, наличие.
- Проверить принадлежность ссылки `https://vk.ru/im?sel=-13456176` нужной группе. В демо использована ссылка пользователя без подтверждения её принадлежности.
- Уточнить адрес, телефон, график и условия доставки. Сейчас сайт ссылается на карточку магазина и не обещает конкретных сроков.
- Подключить согласованную аналитику и необходимые уведомления, проверить на реальных устройствах; убрать демонстрационную маркировку только после замены материалов.

## Визуальный стиль

Иконки интерфейса — Phosphor Icons, единый тонкий штрих (`weight: light`). Знак логотипа — отдельный ботанический SVG в `src/BrandFlower.tsx`; favicon повторяет этот рисунок. В интерфейсе нет эмодзи и шрифтовых пиктограмм. Убраны наклейка на первом экране, повторяющаяся лента слоганов и декоративные звёздочки.
